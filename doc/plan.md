

我计划写个个人内容关系系统。大概如下：

前后端用nodeJS写就行，项目要求简单的 npm i  npm run build npm run start就可以直接运行起来。我自己域名shenyanjian.top，我计划部署在8080上面。

0. 数据库用Sqlite。
1. 默认第一个访问url/admin路由的就是admin用户。可自定义密码，存储密码加盐。
2. admin 可以非常简单的创建其他用户账号、授权其他是否是admin用户。

左侧菜单栏可以有：
1. 消息通知平台。这里需要可以copy link 如 url/api/notification ，其他程序如果向这个notification发送消息 就会在消息通知平台实时显示文字，文字要默认从上向下自动滚动（要有自动滚动按钮），数据库最大存储累计1MB文字消息，多余的就删除。
2. 文件管理。
admin可以自己上传或者下载 多个 文件，要可以自己创建文件夹，其他用户在这里可以下载文件。不要做预览 预渲染，简单上传下载就行。
3. 系统管理
要看到当前系统是不是健康的，实时监控cpu 内存 磁盘，要有一个shell可以访问这个OS。
4. 用户管理：admin 可以非常简单的创建其他用户账号、授权其他是否是admin用户。
